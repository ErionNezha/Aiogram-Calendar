# aiogram_calendar

Kalendar inline për botet aiogram — zgjidh datën direkt në Telegram me butona interaktivë.

`Python` `aiogram`

## 🚀 Live Demo
Hape **`index.html`** në browser — demo-ja ekzekutohet direkt, pa instalime.
Nëse repo është publikuar me GitHub Pages: `https://erionnezha.github.io/Aiogram-Calendar/`

## 📝 Kodi Burim
Kodi i plotë është në dosjen [`original/`](original/) dhe shfaqet krahas demo-s live në `index.html`.

## ▶️ Ekzekutimi origjinal
`pip install -r requirements.txt`, vendos BOT_TOKEN në example_bot.py, `python example_bot.py`.
